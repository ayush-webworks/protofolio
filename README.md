# Ayush Advanced Portfolio
Responsive animated portfolio using only HTML, CSS and JavaScript.

## Files
- index.html
- style.css
- script.js

## Before publishing
1. Replace the profile placeholder with your real photo.
2. Replace demo project text/links.
3. In `script.js`, change `your-email@example.com` to your email.
4. Change GitHub/Instagram URLs in the footer.

## GitHub Pages
Upload all files to a repository → Settings → Pages → Deploy from branch → main → /root.
